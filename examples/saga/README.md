Saga pattern examples.

| File | When to open |
|------|----------------|
| `saga.py` | Basic saga (steps + compensation) |
| `saga_fallback.py` | Fallback / alternate path on failure |
| `saga_recovery.py` | Resume incomplete sagas from storage |
| `saga_recovery_scheduler.py` | Periodic recovery worker |
| `saga_sqlalchemy_storage.py` | SQLAlchemy-backed saga store |
| `saga_fastapi_sse.py` | Saga progress over FastAPI SSE |
| `saga_mermaid.py` | Generate Mermaid diagrams from a saga |

Docs: https://mkdocs.python-cqrs.dev/saga/
